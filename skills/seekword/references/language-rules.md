# 语言细则参考（筛选与制卡补充）

主规则见 SKILL.md。本文件是按语言展开的补充细节，按需加载。

## 停用词/填充词清单（筛选时排除）

- **en**: uh, um, erm, like, you know, okay, okay so, yeah, well, 基础功能词（the/a/of/to/be/have/do/will/can）
- **ja**: えっと, あの, まあ, うん, えー, その, なんか, やっぱり, ちょっと；基础词（見る, 行く, もの, こと, これ, それ）
- **zh_CN**: 嗯, 啊, 就是, 然后, 那个, 这个, 哎；基础词（看, 说, 好, 想, 的, 了, 是, 在, 有）
- **zh_TW**: 嗯, 啊, 就是, 然後, 那個, 這個, 欸；基础词同上（繁体）
- **ko**: 어, 음, 그냥, 막, 네, 아니；基础词（가다, 하다, 것, 수）
- **ru**: ну, типа, как бы, вот；基础词（это, и, в, на, что）
- **fr**: euh, bah, ben, du coup, voilà, quoi；基础词（le/la/les/un/une/et/est/que）
- **de**: äh, ähm, also, halt, so；基础词（der/die/das/und/ist/sind）
- **es**: eh, pues, bueno, o sea, vale, ya；基础词（el/la/los/un/una/y/es/que）

例外：填充词出现在**固定表达**里（如 "you know what"、"まあまあ"）且整体有内容价值时，按整体短语入选。

## 发音补充说明

- **英语**：宽式 IPA、标主重音（ˈ），不带斜杠/方括号；美音（General American）与英音（RP）分别填 `ipa_us`/`ipa_uk`；`ipa` 字段跟随面板口音设置（工具会自动回填）。
- **日语**：NHK 音调式，数字用方括号（例：`はし [1]` 箸）；汉字词也要给假名全读；送气/促音/拨音如实标注。
- **中文**：拼音用 ü 不用 v；声调用符号不用数字；「一/不」变调在 notes 说明。
- **韩语**：RR 转写严格（시=si, 스=seu）；有显著音变（연음/비음화）时在 notes 标注标准发音。
- **俄语**：重音用 ˈ 标在重读元音前；腭化用 ʲ；ё 出现在词条里时读音按 ё 处理并在 notes 提醒。
- **法语**：不标词重音；联诵（liaison）可选标；鼻元音与 ʁ 如实。
- **德语**：长元音标 ː；ich-Laut ç / ach-Laut x 按实际；词重音 ˈ 标主重音。
- **西语**：seseo 中性口音（c/z + e/i 读 s）；重音按书写规则标注。

## 词性中文映射（工具会自动做，agent 直接输出中文即可）

noun→名词 verb→动词 adjective→形容词 adverb→副词 preposition→介词 conjunction→连词 pronoun→代词 interjection→叹词 particle→助词 phrase→短语 idiom→惯用语 numeral→数词

## 语境证据（制卡消歧）

- 对每个选定词，回看原文中该词出现的句子（工具 read 分段里找），以该处用法为准选定义项。
- 一词多义时：优先原文语境义；其余常用义一句话带过（放 notes），不要展开成第二释义。
- 原文用法罕见/非典型：definition 仍写语境义，notes 里补一句通用义与语境差异。
