# 捕获生词（SeekWord）

> 先学再看（Pre-exposure）：阅读/观看之前，先把材料里的高价值生词捕获成学习卡片；之后再回到原文，靠真实上下文强化记忆（Contextual Learning）。

## 触发场景

- "帮我从这段/这个视频里挑生词做卡片"
- "预习一下这篇文章的单词"
- "用 YouTube 字幕学英语/日语/…"
- "看看我的单词本 / 导出单词"

## 三步流水线

```
① capture 捕获 → ② 筛选候选（你）→ save_candidates → ③ 用户挑词 → 制卡（你）→ save_cards → 学习
```

1. **捕获**：`seekword(action="capture", source=…)`。来源四选一：
   - `text`：用户粘贴的文本（最常用，把用户消息里的原文完整传入）
   - `youtube`：`url` 传视频链接或 videoId，工具自动多客户端降级抓字幕
   - `file`：本地 `txt / md / srt / vtt / json3` 文件路径
   - `web`：`url` 传 http(s) 网页链接，工具做基础正文提取
   捕获成功会返回 `contentId` 与统计（字符数/行数/语言），后续所有操作都靠它。
2. **读原文**：长原文用 `seekword(action="read", contentId, offset, limit)` 分段读完整内容（返回会告知剩余量）。筛选必须基于原文，不要凭标题猜。
3. **筛选候选**（你完成）：按下方「筛选规则」从原文挑高价值生词，调 `seekword(action="save_candidates", contentId, terms:[{term,type}])` 入库。候选会出现在面板「学习」页，用户勾选后让你制卡。
4. **制卡**（你完成）：对用户选定（或面板带回）的词，按下方「制卡规则」生成卡片，调 `seekword(action="save_cards", contentId, cards:[…], selected:[…])` 入库。`selected` 传用户最终选定的词列表，工具会按选择顺序对齐补位。
5. **学习**：卡片入单词本后，告诉用户到侧栏「捕获生词」面板的「学习」页翻卡（←/→ 切换、空格收藏），或直接在对话里呈现卡片。

## 筛选规则（候选词）

- **证据优先**：term 必须是原文中的**表面形式（surface form）**——照抄原文字符串，不还原词元、不音译。不确定在不在原文里，宁可不选。
- **教学价值排序**：对新学者的新鲜度/难度 > 语义密度 > 惯用搭配 > 局部词频。挑真正值得学的新词、难词、习语、搭配，跳过学习者几乎必会的基础词（en: have/people/time/thing；ja: 見る/行く/もの/こと；zh: 看/说/好/想；ko: 가다/하다/것）。
- **多词表达**：惯用的、难逐字直译的短语优先（type 标 `phrase`，单词标 `word`）。
- **语言门控**：只保留源语言原词——英语允许撇号/连字符；日语用假名/汉字混合原形、禁止罗马字；中文只要汉字、禁止拼音词条；韩语禁罗马字；俄语禁拉丁转写；法德西保留原声调符号（é ä ñ ß）。
- **排除噪声**：填充词/语气词（en: uh/um/like/you know；ja: えっと/あの/まあ；ko: 어/음/그냥；ru: ну/типа；fr: euh/bah/du coup；de: äh/also；es: eh/pues/o sea；zh: 嗯/啊/就是/然后）、品牌名、游戏 ID、话题标签、型号、时间戳、未本土化的外语借词。
- **数量**：默认 15–30 个（工具上限 60）。材料很短就少挑，别凑数；不确定就宁缺毋滥。

## 制卡规则（卡片字段）

每张卡片：`term / reading / ipa / ipa_us / ipa_uk / pos / definition / examples / notes`。

**发音规则（按源语言，硬性约定）**：

| 源语言 | reading | ipa | 备注 |
|---|---|---|---|
| 英语 | 留空 | `ipa_us` + `ipa_uk` 都给，`ipa` 跟随面板口音设置 | 宽式 IPA，标主重音 ˈ，不带斜杠括号 |
| 中文 | 汉语拼音带声调（ü，不用数字调） | 留空 | 一二三四声用 mā/má/mǎ/mà |
| 日语 | 全假名 + NHK 音调数字，如 `あめ [0]` | 留空 | 禁罗马字作主读音 |
| 韩语 | 国语罗马字 RR（시=si） | 留空 | 禁混其他转写 |
| 俄语 | 留空 | IPA（莫斯科标准，标重音与腭化 ʲ） | јё 要如实 |
| 法语 | 留空 | IPA（鼻元音 ɑ̃ ɔ̃ ɛ̃ œ̃、小舌 ʁ，不标重音） | |
| 德语 | 留空 | IPA（长音 ː、ich/ach 作 ç/x） | |
| 西语 | 留空 | IPA（中性 seseo，标重音） | |

- 释义语言（definition/notes/pos 的语言）跟面板「释义语言」设置（默认中文）；用户没说就用设置值。
- 中文释义时 pos 用中文词性（名词/动词/形容词/…）；名词可在 notes 标性/数，动词可标变位/体。

**例句（examples）**：每个词恰好 2 组，每组一个字符串、内含两行（`\n` 分隔）——第一行源语例句，第二行释义语言翻译。例句尽量贴原文语境（词在原文里的真实用法），不含发音行、不含列表符号。

**definition**：短而准的学习者释义，**贴合该词在原文里的语境义**。语境不足难以定义项时，给最小释义并在 notes 标 `insufficient_context`。

**notes**：关键语法/搭配/易错点/文化背景，可空。韩语可备注敬语/不规则变形/音变；西语可备注语域/区域变位；德语可备注可分前缀/性；俄语可备注体/变位。

## 输出规则（对话里呈现卡片)

制卡入库后，向用户按顺序输出：

1. **卡片清单表格**：`| 生词 | 读音/音标 | 词性 | 释义 |`（每行一个词；音标英语显示 `ipa`，中日韩显示 `reading`）。
2. **学习提示**：告诉用户卡片已入单词本，到侧栏「捕获生词」面板「学习」页翻卡复习（←/→ 切换、空格收藏）；想导出在「单词本」页点「导出 CSV」。
3. **页脚**：逐字附上工具返回的 footer（材料标题 · 卡片数 · 记录 id）。

### 呈现纪律

- 释义/例句来自你的制卡结果，逐字一致；不要在对话里另编第二套内容。
- 工具回执里的 warnings（如「未在原文找到」）如实告知用户，不要隐瞒。
- 用户问词义时直接答，不必每次都走完整流水线；只有用户要"做卡片/存单词"时才调 save_cards。

## 断点续跑

- candidates 已入库但用户还没挑词：直接引导用户去面板「学习」页勾选，或让用户直接说"就学这几个：…"。
- 用户报 contentId 继续操作时（补卡/删料/导出），先 `list` 或 `wordbook` 核对记录存在再动。

## 面板与导出

- 侧栏「捕获生词」面板：**学习**（翻卡+键盘导航+收藏）、**单词本**（全部卡片/来源过滤/搜索/收藏/CSV 导出）、**概览**（材料列表+统计）、**设置**（释义语言/口音/YouTube 代理）。
- 用户要文件时用 `seekword(action="export")` 导出带 BOM 的 CSV（Excel 直接打开不乱码），把返回的文件路径给用户。
